## 用户新增确认（优先于原表理解）

v2.2 是增量能力，连续轻剧情 Vlog 与剪辑型短片均是一等路径。ED02/ED04 增加 CONTINUOUS / EDITED / HYBRID 叙事组织路由，默认根据真实剧情自动判定；摄影模式独立。ED06/ED07 在素材清单中定义连续动作链、依赖关系、各实际边界关系；连续必须严格T03交接，非连续按Story状态版本。ED08 不废除原顺序生成路径或强制非线性/EDL详细输出；ED09 增加连续日常、连续5分钟规划、剪辑故事、混合旅拍四类回归，及“跨任务编号不同但动作连续”“连续边界状态不一致拒绝”“不能因长片强制重排”。所有技巧按必要性选择。
