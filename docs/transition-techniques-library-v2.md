# Vlog AB Director v2：跨 Part 创意转场技巧库

> 状态：**T03B 已接入的摄影/剪辑技巧参考库**；不是 H3 实机成功率报告  
> 适用：常规15–300秒成片的连续、剪辑及混合叙事，可按需用于单任务内或实际播放边界；单次H3仍独立15秒。  
> 设计重点：**根据故事需要提出转场建议，而不是要求每个 Part 必须使用转场。**  
> 关联：[v2 详细设计](design-v2-director-engine.md) · [分阶段实施计划](implementation-plan-v2.md) · [T03B 转场导演](../references/transition_director.md) · [静态测试](../tests/transition-cases.md)  
> 声音规则：生成阶段始终**无 BGM**；后期配乐由创作者完成。

## 1. 核心原则：转场是可选建议，不是强制流程

- **先有剧情再找转场**：只有当地点、时间、情绪、动作、视觉关系或叙事重点出现自然可用的连接点时，才提出技巧性转场建议。
- **允许 NO_TRANSITION**：每一个 Part 边界首先判断「直接自然剪接是否更好」。答案是可以，且是正式的有效决策，不应被 QC 判错。
- **不以时长或 Part 数量推算必须有多少转场**：120 秒、8 Part 不等于一定要安排 7 次、3 次甚至 1 次「神转场」。没有合适场景就全部普通切。
- **高光不过度**：如果一条片子已经具有强烈的情绪、对话或动作连续性，转场往往应该隐身；有强烈时空跃迁或视觉呼应时，可将一处技巧性转场作为惊喜。
- **仅在合适且获授权时应用**：默认 Auto 先进行场景适配性评估，合适时只输出简短建议，**不改动原有 Prompt**。只有用户明确选用技巧，或明确委托导演按需直接安排且物理可行时，才将「前 Part 结尾 + 后 Part 开场」成对镜头纳入规划。未选用时只保留正常衔接，不强行改写。
- **用户有最终控制权**：用户指定「不用特殊转场」「只给建议、不应用」「直接用遮挡转场」时，应按约束执行；如果物理或模型实现难度很高，应提示可行方案/替代方案，而非保证效果。
- **只讨论摄影与剪辑技巧**：不以淡入淡出、交叉叠化、模板式闪白/故障效果或软件一键转场充数。隐藏切镜所需的真实遮挡、真实失焦与运动模糊除外。

## 2. 决策：何时不推荐、何时推荐

每个边界单独执行：

1. 明确 **story_boundary**：同地同动作 / 地点切换 / 时间跳跃 / 情绪转折 / 视觉隐喻 / 新章节。
2. 先评估直接硬切是否已经清楚自然：若是，则优先 `NO_TRANSITION`。
3. 只有在存在真实连接物（遮挡物、门框、水面、同形物）、连续动作、同向运镜或有意义的空间转换时才检索技巧库。
4. 对候选做约束检查：故事意义、视觉可匹配、角色/道具状态、动作复杂度、素材/参考图、AI 生成风险、剪辑成本、节奏适配。
5. 输出 `none` / `suggest_only` / `planned_pair` 三种状态：
   - `none`：无特殊技巧，正常剪接，**完全合理**；
   - `suggest_only`：给出一种可选建议，保持现有生成 Prompt 不变；
   - `planned_pair`：用户已选用或明确授权导演按需实际安排，且物理/时长可行时，才把前后两端镜头设计一起交给 Prompt 装配流程，并附剪辑点说明；正式多段 H3 装配留 T05。
6. 如有多个候选，最多挑出最适合的少数，不罗列一堆无关花样；有把握不足时默认不建议。

**不可为了满足「每个 Part 都要一个转场」而添加无意义动作。** 尤其要避免为转场强行让人物做复杂动作、增加手机/道具、破坏口型或拖延叙事。

## 3. 技巧分类与具体拍摄/剪辑方案

风险等级：L（相对易实现）、M（需要画面方向/动作精准配合）、H（高复杂度；建议样片验证、剪辑备选）。等级是**设计预估，不是 MiniMax H3 实测成功率**。

| PT05 | 镜面 / 玻璃穿越 | 摄影机向镜面反射靠近直到反光占满 → 下一地点由相似反光后拉显景 | 反光/局部遮挡 | H |
| PT06 | 车窗 / 车门穿越 | 摄影机沿车窗推进、窗框挡屏 → 下一地点从另一个车窗退开 | 车框遮挡 | M |
| PT07 | 书页 / 画册世界 | 翻页让纸面盖住镜头 → 下一场景从相近纸面或画中场景揭开 | 纸面满幅 | H |
| PT08 | 雨滴 / 水雾覆盖 | 水滴、雾气真实掠过摄影机直至水纹占大部 → 下一地点水珠退去露景 | 前景水珠最密处 | H |

**水池穿越完整样例**：

- 前 Part 尾镜：摄影机**安全地**靠近溪水/水池水面，画幅逐渐被波纹和气泡覆盖；以色泽、运动方向和水纹形态作为出场锚点，不要求演员危险潜水；
- 后 Part 首镜：从**相同方向的水纹和水泡**起镜，摄影机向上离开水面露出另一个海滩/湖边；
- 剪辑师在水纹占屏最大的相似帧处硬切；允许配水声和泡沫 Foley；**无 BGM**；
- 写实题材中这是摄影和剪辑造成的地点跳切；奇幻题材中可作空间门户隐喻，但仍不要求一次独立生成任务真实「无切穿越两地」；
- 当水纹不稳定或参考图难以对齐时，回退至水面图形匹配或普通场景硬切，不要强求「神转场」。

## 4. 场景适配矩阵与禁忌

| 题材 | 优先可能建议 | 通常不建议 |
|---|---|---|
| 写实旅行、街头 Vlog | OC02/OC03、AC01/AC04、CM01、GM02 | 连续多次超现实门户 |
| 情侣 / 双人互动 | OC01、AC02、AC04、GM04 | 双人同时复杂抛接道具 |
| 安静、治愈、低对比柔光 | GM01/GM02、OT01/OT02、OC03 | 频繁大幅快速甩镜 |
| 时尚人物展示 | OC05、CM03/CM05、GM04/GM05 | 无原因连续大景别航拍 |
| 节奏很快的旅拍混剪 | CM01/CM02、AC02、OC06 | 方向不一致的快速运镜 |
| 梦境、奇幻、时间穿越 | PT01/PT02/PT03/PT05/PT07 | 宣称复杂镜头必定一次成功 |
| 古风 / 无现代摄影道具 | OC05、PT03、GM04、OT02 | 现代手机或 UI 入镜 |
| 对话主导或情绪细腻片段 | **NO_TRANSITION** 或视线/动作自然切 | 为炫技打断对白、情绪、口型 |

**示例判断**：
- 两个 Part 在同一海边，人物正在讲述心事 → 直接硬切 / L-Cut 保持自然，多半无需「神转场」；
- 从城市进入森林且画面恰好有门框或树干 → 可**建议** OC02/OC03；
- 在泳池边转到海岛梦境 → PT01 可能很有记忆点，但应标 H 风险并提供回退；
- 120 秒连续叙事也可以全程不用复杂技巧。

## 5. 跨 Part 推荐字段（仅对候选或选中者）

最小数据结构（用于规划，不是直接给 H3 的原生语法）：

`boundary_id, from_part, to_part, story_reason, transition_decision(none|suggest_only|planned_pair), transition_id(optional), technique_family, risk, implementation_notes`。

当选择 `planned_pair` 时，额外记录：
- **Outgoing**：上一 Part 最后一镜应呈现的机位、高度、景别、遮挡形状/动作相位、运镜方向与速度、最后可剪画面状态；
- **Incoming**：下一 Part 第一镜应从何种构图/纹理/动作/运镜进入，如何揭露下一个空间；
- **Edit Point**：真正的剪点依据，例如满幅遮挡、运动模糊峰值、形状重合或动作相位；
- **Physical Continuity**：人物身份、衣着、左右手、道具、场景、光影哪些需继承，哪些是被允许的时空跳跃；
- **Audio Bridge**：只允许环境音、人物对白/画外音和 Foley，禁止生成 BGM；
- **Fallback**：失败时回退到匹配动作、低风险遮挡或普通硬切；
- **Editorial Effort**：后期是否需要裁切、调速、遮罩或音画对齐；
- **Estimated Duration Loss**：两端可剪的冗余素材长度及对总片长的影响，不能擅自用素材原始名义长度代表剪后净时长。

**不推荐 / 未选用**时，`transition_id` 可为空；QC 不得报错。一个 Part 边界也可以只给一句「本处直接硬切最自然」，无需大段解释。

## 6. 转场与长片节奏

### 6.1 成片上限300秒，素材任务数与转场次数分别规划

- 本Skill规划单元仍为独立15秒任务；成片目标0<T≤300秒，常规15–300秒。仅用新素材、无复用时，ceil(T/15)是无损任务数下界；实际有限任务预算由保留率、补镜和用户成本约束决定。
- **最长成片300秒**。20个任务仅代表300秒无损新素材基线，非任务数硬上限；精确目标需按实际保留区间与EDL核算。
- 目标在范围内不代表一定有足够可用素材；预算不足时报告冲突，按实际可用余量、明确补镜预算或短版处理，不宣称H3支持任意单次生成长度。
- 固定8任务的120秒、固定20任务的300秒都没有裁切余量；若损耗1秒且无其他可用素材/复用，则分别仅剩119/299秒。经授权补镜须另计有限任务预算；禁止无依据的自动无损对齐承诺。连续链按T03承接，非连续按Story状态，实际播放边界才决定转场。现行规范见 [Timing Engine](../references/timing_engine.md) 与 [Footage Plan](../references/editing/footage_planning.md)。

## 7. QC 与回归

**选择决策检查（对所有边界）**
- 有边界判定：none / suggest_only / planned_pair；**none 是正确结果**；
- 有客观叙事连接理由才推荐技术；
- 不要求每 Part 必须安排技巧性转场，也不设数量下限；
- 用户不希望特殊转场时尊重其要求；
- 不用淡入淡出、交叉叠化、模板特效替代实拍/剪辑技巧。

**只对已选用 planned_pair 做硬 QC**
- 两端镜头均被定义，剪辑点明确，不能只生成「神奇穿过去」；
- 景别、运动方向、速度、遮挡形状、动作相位在可实现范围匹配；
- 人物/道具/手/参考资产映射与 Part 状态继承无冲突；
- 高风险技巧必须说明可能需要后期辅助和可回退选项；
- 成片总时长与裁切后的净时长核算明确；
- 所有模型 Prompt 依然无 BGM，`non_diegetic_music: N/A`。

**回归示例**
1. 30 秒同场景对话 → none；不强行安排神转场。
2. 45 秒旅行不同地点且有路边树干 → suggest_only OC02（不是立即强制写入 Prompt）。
3. 用户要求使用甩镜 → planned_pair CM01，验证两端方向/速度。
4. 用户提出「穿越水池进入另一场景」→ 建议或选用 PT01，两个镜头+切点+风险/回退齐全。
5. 90 秒治愈慢节奏 → 可全程 none 或少量构图匹配，不强行高速转场。
6. 120秒固定8任务兼容例、300秒固定20任务零余量例及24任务预留裁切例：按预算核算，均无固定转场次数。
7. 用户强调「只提供建议，不要调整 Prompt」→ suggest_only，原片 Prompt 不改变。
8. 用户选择 Classic AB，镜头节奏已经锁定 → 只推荐与现有尾/首镜兼容的技巧，否则 none。
9. 转场两端参考素材不匹配 → 回退 none，不伪造模型能做到的跨任务同步。
10. 所有案例无内生 BGM，保留用户实测的中文画外音。
