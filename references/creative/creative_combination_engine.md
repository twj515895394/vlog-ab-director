# 创意组合与差异化引擎

本模块以自然语言规则生成创意，不是伪随机程序、热度预测器或固定剧本库。输入来自 creative_director.md 的 C01，输出供 collaborative_discussion.md 使用。

## 1. 输入与筛选

先保留人物设定、世界观、关系、时代、锁定题材、时长、对白、画幅、素材、禁止项、用户创意偏好。将每项区分为 locked / preferred / excluded / unknown / assumed。硬约束冲突先处理，未知素材不当作已上传。用户给出真实人物，仅基于其提供的事实或明确虚构的情境，不凭形象推断经历。

从 genre_library.md 中选题材，结合 micro_story_structures.md、creative_seed_library.md、character_interaction_library.md、emotional_arc_library.md 的条目。用户明确只要旅拍就在G02内变化，而非默认引入无关题材；用户没有方向则跨驱动力探索。可用自定义种子/结构，不受库枚举穷尽限制。

## 2. 组合机制

先选人物驱动力（体验/关系/探索/审美/情绪/趣味/微目标），再生成：
- 内容：主/辅题材 + 人物关系 + 世界观与真实素材。
- 动因：一个具体触发（或非剧情视觉母题）+ 人物行动/选择。
- 叙事：主结构 + 情绪路径 + 可见记忆点 + 结尾。
- 实施：2–5个可见节拍（长片按容量增加）+ 预估时长 + 动作/空间/道具负担。
- 表达：用户给定美学、视角偏好、必要对白或纯现场声。导演策略仅建议，真正选择由T01。

检查因果、时间容量、人物主体性，优先用少量角色和核心物件。无事件的时尚展示可用姿态、材质和构图母题代替剧情目标。创意不要靠大量对白解释，也不要通过虚构魔法效果实现。

### 2.1 五种发散方法（结合而非固定套用）

| 方法 | 如何变动 | 示例 |
|---|---|---|
| 横向切换 | 保留人物/风格，切换驱动力和结构 | 同一旅人：寻找照片/偶然发现/与同行者互动 |
| 纵向变体 | 保留主事件，改选择、情绪或结尾 | 找到旧物后归还/留给自己/轻松放回 |
| 人物关系变换 | 在用户未锁定且明确是虚构的前提下调整关系 | 同一场等待变为独处/朋友/镜头外邀请 |
| 元素融合 | 从两创意提炼可兼容机制，重建单一因果链 | 地图探索+回头等待：两人一起发现小径 |
| 反向推演 | 从记忆点/结尾倒推必要事件，避免堆镜头 | 夕照里空椅变成并肩坐下，开场建立空椅 |

### 2.2 候选指纹与差异约束

内部每个候选记录 fingerprint={genre,driver,trigger,structure,ending,motif}，另外保留 relationship/action。比较语义而不只比字符串；两条仅换咖啡→茶、街道→小巷而核心事件和情绪结果相同，算近重复。无用户指定同机制变体时，优先在驱动力、事件、结构、结果、关系中至少改变两个维度。用户明确要同机制不同风格或多个结尾时允许只改该维度，不误判为低质量。对于15秒非剧情审美，可比较人物姿态/视觉母题、空间用途和情绪而非强推剧情差异。

若所有候选近似，保留最贴合的一条，另外挑不同驱动力重新组合；不重复上轮被拒选项。排序参考用户贴合、人物中心、记忆点、可见情绪、生成难度、互相差异，定性推荐并解释取舍；不打伪精确概率，不承诺爆款。

## 3. 产出候选

默认 ZERO/CHARACTER_ONLY 3–5条；VAGUE 2–4个变体；用户要求数量优先。不为凑数量重复。每条用稳定ID（A/B/C或F01等）、标题、主题材、1–3句人物主体内容、核心记忆点、建议时长与难度（低/中/高及缘由）。必要时列假设和素材需求，不要求呈现内部指纹。若仅想要创意方向可简短，不直接写六字段、图像提示词或实际分镜。末尾可问一个有价值的问题，如更偏轻松、情绪还是关系，或邀用户混合任意两条。

### 难度参考

低：少量人物和场景，日常小动作，普通切镜；中：双人轮次、交接道具、多个局部地点或转场设想；高：复杂物品操作、多人物同步、镜面身份/连续动作、跨任务精确匹配。高难应提供更稳替代，不直接删除用户锁定内容。所有预计均为文本规划，不是模型成功率。

## 4. 反馈适配

按讨论协议记录来源和排除项，融合时明确保留何种机制以及舍弃内容；改变核心内容创建新revision，旧确认失效。用户说只改结尾就不要换人物、时代、核心事件。拒绝某元素则过滤后续候选；全面拒绝时从新的驱动力重新发散。在创意未获制作授权时不得将候选自动改写为最终模型Prompt。确认/委托后交给 creative_brief.md 和 creative_quality_control.md。
