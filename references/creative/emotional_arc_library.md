# 情绪与人物表达库（E-ID）

情绪不是滤镜名，也不要求每条短片有剧烈变化。以人物可见表现、导演节奏、场景/现场声表达；内心独白可选，生成阶段始终无BGM。

| ID | 情绪方向 | 初态→触发→尾态 | 可见动作/声画 | 避免项 |
|---|---|---|---|---|
| E01 | 松弛 | 忙碌→停下→松弛 | 放下物件、呼吸、环境声保留 | 机械念鸡汤 |
| E02 | 治愈 | 疲惫→小小体验→安定 | 坐下、自然微笑、光线变化 | 强设疾病/创伤 |
| E03 | 浪漫 | 期待→回应→亲近 | 等候、眼神和微小动作 | 不明确关系就亲密化 |
| E04 | 怀旧 | 熟悉→触旧物→回味 | 手触照片/物件、停顿 | 虚构真实记忆 |
| E05 | 自由 | 约束→选择→轻盈 | 转向、迈步、开放空间 | 强迫一定有前史 |
| E06 | 好奇 | 观察→发现→惊喜/理解 | 视线转移、脚步停止 | 无因果乱换景 |
| E07 | 喜悦 | 日常→小完成→自然笑 | 展示成品、身体松开 | 夸张表演 |
| E08 | 孤独 | 独处→观察→保持/温暖 | 空间留白、自然动作 | 将独处等同悲伤 |
| E09 | 释怀 | 牵挂→微选择→放下 | 放回物件、转身 | 无依据悲剧 |
| E10 | 幽默 | 预期→偏差→会心一笑 | 反应、静默半拍 | 羞辱/危险整蛊 |
| E11 | 仪式感 | 准备→专注→完成 | 摆放、整理、停留 | 复杂连续小动作 |
| E12 | 梦境 | 现实→母题变化→留白 | 构图、光、场景合法跳跃 | 强制魔法/叠化 |
| E13 | 宁静 | 平静→观察→平静 | 轻步、风声、稳定姿态 | 无理由强加冲突 |

情绪可以稳定，也可以仅做轻微弧线。15秒一个有效触发已足够；表演与对白不同时过载。跨Part变化要有时空或叙事理由，后期音频桥接不承诺自动共享。
