# Creative Director — C00–C06 人物短视频创意入口

设计：[v2.1详细设计](../../docs/design-v2.1-creative-engine.md)。先判创作需求，再选择题材；这里不是 H3 摄影模式路由。适用于以人物为主体的15–300秒轻剧情、弱剧情和非剧情审美短片。用户的明确需求优先；不借创意强制改写其剧本。

## C00 双维入口识别（每轮）

idea_maturity：ZERO（没有点子）、CHARACTER_ONLY（仅角色/参考图/世界设定）、VAGUE（有模糊事件、主题或情绪）、READY（完整剧情，或已经足够明确的日常/审美拍摄任务）。request_goal：IDEAS（只要点子）、DEVELOP（一起讨论）、BRIEF（只要定稿/剧本）、PROMPT（进入成品生成）、MODIFY（修改已有成果）。

| 输入 | 路径与当前产物 |
|---|---|
| 想拍短视频，没有点子 | ZERO/DEVELOP → 直接给3–5个差异化具体概念 → DISCUSS，不生成H3 |
| 只有一个角色或一张图 | CHARACTER_ONLY → 围绕已知人物特征构思多个情境，图中看不出的经历/关系不猜 |
| 想拍雨天等人的故事，但没想好 | VAGUE → 保留等待主题，提出两至四种变化 |
| 只帮我想10个创意 | IDEAS → 用户指定数量优先，交付点子即停 |
| 直接把完整剧情做成30秒Prompt | READY/PROMPT → 最小简案，direct_ready确认，QC后直接T01 |
| 没想法，你决定一个，直接给15秒Prompt | ZERO/PROMPT + 明确委托 → 内部构思/取舍、简案、QC、交接；不再确认 |
| 有旧Prompt，仅改镜头/光线 | MODIFY → 用户同意的创意核心不变，走现有导演执行层并复核；若改核心则REOPEN |

不因为用户用「短视频」「Vlog」字样就判断要立即出成品；没有创意时「我想创作」不等同授权。如果用户已有明确叙事/非剧情目标并明确要成品，不回到发散（哪怕无完整剧本）。只求方向或剧本，不强迫进入制作。处理互斥硬约束时询问关键选择，不编造。

## C01 意图与约束

读取当前对话已知人物/关系/世界观、素材、时长/画幅、风格、对白、固定台词、禁用元素、拍法、转场偏好。区分用户已锁定/偏好/未知/助手暂定；本轮明确修订更新版本。没有人物时可用多样化的角色设定提出点子，不要求先填表。仅图像时只用可见造型与用户提供身份，不从外观推断职业、性格、私人经历或关系。素材未确认可用时标待提供，不虚构上传/引用。只有真影响决定且无法继续时问一个聚焦问题，其余可逆项明确暂定。

## C02 题材检索

读取 [题材库](genre_library.md)，分主方向与辅助方向；同时根据候选需要读取 [微叙事](micro_story_structures.md)、[种子](creative_seed_library.md)、[关系](character_interaction_library.md)、[情绪](emotional_arc_library.md)。不直接将题材库照搬成推荐清单。人物驱动力可为体验、关系、探索、审美、情绪、趣味或微目标；无冲突无目标的审美作品合法。

## C03 候选提案

按 [组合引擎](creative_combination_engine.md) 过滤、组合、具象化、去重与可行性评估。默认3–5个概念（模糊已有方向2–4个发展变体），含ID、片名、题材、核心内容、人物驱动力、可见记忆点、建议片长和相对生成难度。用户要数量或特定题材则尊重。选项要在核心事件、驱动力、关系、结构或结尾上真正不同，不只换地点/衣服。默认只呈现下一步需要的信息；不自动出图、不声称爆款预测。

## C04 多轮共创

必须读取 [讨论协议](collaborative_discussion.md)。保留会话内约束、已拒绝元素、稳定提案ID、版本、反馈、草案与当前确认。用户喜欢某方向仅聚焦，细化/融合/比较/重新发散均允许；问下一步最有价值的问题，不问长表。根据反馈更新具体方向而非复制上一轮清单。

## C05 简案与确认

按 [Creative Brief](creative_brief.md) 形成可审核简案。显式确认当前简案或明确委托才允许制作；仅喜欢/挑选/讨论中的OK不代表生成授权。READY且明确请求成品可 direct_ready。仅要灵感/简案时即使定稿也不进入H3。修改核心内容需撤销旧确认，直接按新要求生成属于当前修订授权。

## C06 创意QC / T01交接

必须读取 [创意QC](creative_quality_control.md) 并逐项核查。未解决硬冲突、需要用户确认或仅讨论的状态不得交付最终H3 Prompt。通过且交付意图是PROMPT时，把当前确认简案先进入 [Narrative Architect](../narrative/narrative_architect.md) 与 [Editing Director](../editing/editing_director.md)，再映射到原 T01 Director Brief；不在Prompt新增内部字段。T01–T06保持旧优先级与约束：15秒独立任务、最长300秒成片、有限独立任务预算、Classic仅固定6×2.5s、无BGM、真实资产与局部编号、转场默认仅建议、已验证中文VO、最终QC。执行层发现必须改核心故事时回REOPEN；用户仅修改执行细节则重新执行相关 T02–T06。

非核心内容可解释范围并提供可行简化；不要为遵守人本定位改写用户明确的纯风景/产品请求。涉及真实人物的纪实创作以提供的事实为限。创意质量和模型视频证据分别记录，不承诺物理/声画效果。
