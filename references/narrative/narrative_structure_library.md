# 剪辑型叙事结构库

来源理论参考 [SRC01/03/05/06](../editing/sources.md)；以下为创作规划，不是机械套路。旧微叙事S-ID可作为局部节拍，N-ID为全片结构。

| ID | 结构与作用 | 使用条件/风险 | 实施 |
|---|---|---|---|
| N01 | 线性：事件因果顺序 | 清晰主线，避免全过程 | 选择关键节点，省略琐碎 |
| N02 | 先果后因 | 结果激发问题，过去能解答；不能虚假承诺 | 现在状态→过去→回到现在 |
| N03 | 闪回/插叙 | 回忆提供有意义信息；缺线索则混乱 | 两时期独立素材，建立/返回线索 |
| N04 | 闪前/想象 | 明确未来或假设的叙事地位 | 不冒充实际已发生事实 |
| N05 | 平行线 | 同时或主题相关的两组人物行动 | 记录时序和空间；交织节拍 |
| N06 | 环形呼应 | 开头母题结尾变化 | 角色状态/信息新增，非填时长 |
| N07 | 成长/历程蒙太奇 | 时间跨度大，变化可见 | 挑代表阶段，身份形态分别锁定 |
| N08 | 对比/联想 | 关系或情绪意义来自邻接 | 不把联想剪成物理连续 |
| N09 | 主题观察/视觉诗 | 弱剧情、审美、微纪录 | 人物主题/动作/声音母题，不强推冲突 |
| N10 | 多章节人物故事 | 2–5分钟完整目标和结果 | 主线贯穿，章节各有功能和必要信息 |
| N11 | 碎片式记忆 | 以人物当下体验串起记忆片段 | 清楚的情绪与时域归属，勿乱序 |
| N12 | 双视点重述 | 同一事件不同角色知情范围 | 同一事件锚点一致；明确新信息而非重复填充 |
