# Editing Director — 兼容连续轻剧情与片段式叙事

确认/委托Creative Brief且制作意图与创意QC通过后：[Narrative Architect](../narrative/narrative_architect.md) → [Auto](editing_auto_strategy.md) → [Decision](editing_decision_engine.md) → [Footage](footage_planning.md) → T01–T04 → [EDL](editing_timeline.md) → T05六字段 → T06与[Editing QC](editing_quality_control.md) → [后期方案](post_production_plan.md)。

CONTINUOUS：普通顺序日常/连续互动优先，故事/生成/播放可完全同序，严格T03承接；保持原输出方式。EDITED：按剧本需要省略、回忆、平行、重组及独立覆盖；逐边界判断，仍可有连续镜头。HYBRID：连续场景内部严格交接，章间允许合法时空跳跃。三者与Classic/Adaptive/Cinematic摄影策略独立。不得按时长强制切换；用户明确连续时不改成蒙太奇。单段/简单连续多段保持Standard及必要交接；非线性或实际裁切等提供可执行预剪表。只要创意或建议时不提前出成品。已有素材仅用真实提供信息，否则条件化计划。
