# 第九类：创意转场适配

复用 [46 技巧库](../../docs/transition-techniques-library-v2.md) 与 [T03B](../transition_director.md)，不重编号。普通连续性、视线、叙事组织剪辑可自主规划。特殊双端视觉/运动匹配仍须授权：none普通切；suggest_only只建议、不改Prompt或已选剪辑；planned_pair仅用户明确选用或委托实际安排，满足双端资产、方向/速度/颜色/形状、可剪点、状态及风险回退。
相邻EditItem才是真实播放边界；连续场景比较保留点状态；跨时域按剧本及授权的视觉条件匹配，不强迫不同事件承接。无需神转场数量；无清晰叙事理由直接none。实际裁切重算净长。禁止声称模型可自动跨空间一镜到底。参考SRC07/SRC09。
