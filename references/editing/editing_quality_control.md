# Editing QC — 独立剪辑门禁

不替代Creative QC和T06。证据PASS/FAIL/UNKNOWN/N/A；文本计划不等同于真实视频。任何硬冲突先修复，改变核心已确认剧本需重开确认。

| ID | HARD | 修复 |
|---|---|---|
| ED-H01 | 0<T≤300且有限任务/成本预算，真实/预计素材区分 | 修正预算/授权或短版 |
| ED-H02 | 每任务15s局部闭合、Classic与用户锁定 | 重新按T02 |
| ED-H03 | 三轴ID及源/目标/时期版本合法 | 修正映射 |
| ED-H04 | 源范围/目的连续、净长、复用理由 | 重算EDL和源并集 |
| ED-H05 | 每边界剧情关系/状态合法；连续链严格承接 | 复核保留点/依赖，按故事版本；不能强制解耦 |
| ED-H06 | 当前创意确认、制作意图及用户约束 | 停在建议或REOPEN |
| ED-H07 | 技巧前提、特殊转场授权与回退 | 普通切或降复杂 |
| ED-H08 | 音轨/源区间/口型、无BGM | 后期混音/正常切 |
| ED-H09 | 人物主体、必要信息和关键动作覆盖 | 增减合理镜头 |
| ED-H10 | 独立六字段、图号、交付数量 | 修复缺失与清单 |
| ED-H11 | 不伪造实际剪点、素材、实测成功 | 标计划/UNKNOWN |
| ED-H12 | 组织路由服从剧本；章节/持续依赖与预算联动 | 保留连续剧情或合法混合，复核下游 |

| ID | SOFT | 检查 |
|---|---|---|
| ED-S01 | 情绪 | 剪点服务人物感受 |
| ED-S02 | 故事 | 因果、选择及结果可理解 |
| ED-S03 | 节奏 | 有效信息与留白 |
| ED-S04 | 信息 | 知情差、设置与回收 |
| ED-S05 | 注意力/空间 | 视线、轴线、方向 |
| ED-S06 | 表演 | 关注姿态/眼神/反应 |
| ED-S07 | 覆盖 | 有效而经济，不堆补镜 |
| ED-S08 | 声音 | 自然声、声画关系、后期可实现 |
| ED-S09 | 克制 | 无需展示技巧数量 |
| ED-S10 | 美学 | 主题与视听一致 |

连续、剪辑、混合均合法；五分钟不必蒙太奇，15秒亦不必线性。复核实际故事需求，不以长短判定连续。先修hard再优化soft；用户无需看内部表。修改预算或剪点后重新校对状态和音轨；未真实运行Skill/H3不得称实测。
