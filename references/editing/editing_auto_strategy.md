# Editing Auto — 双维路由与自动剪法

先据实际剧本及用户明确要求选择 organization_mode：CONTINUOUS（连续动作链/场景内互动/传统Vlog顺序）、EDITED（核心表达需要片段组织/回忆/蒙太奇等）、HYBRID（局部严格连续、部分叙事跳跃）。没有必要重排优先CONTINUOUS；不依据长短、题材或A/B策略机械路由。用户指定优先；连续性需要按每个边界确认。AUTO选择后不要求用户逐个指定普通技巧。

| 信号 | 候选手法 | 过滤条件 |
|---|---|---|
| 生活、同场动作 | CO01/CO02/CO03/EM02 | 严格状态承接；不强制切碎或重排 |
| 人物旅拍、职业与成长 | TE02/TE03/MO01/IC03 | 看实际剧本；连续过程保持，省略有理由 |
| 对话、互动、发现 | CO04/EM01/AU01/AU02 | 发言者、轴线、真实音轨 |
| 治愈、怀旧、艺术 | MO02/EM04/RY02/MO07 | 可无剧情但仍以人为主体 |
| 过去现在有因果 | TE05/TE06/IN03 | 角色状态版本及回归线索 |
| 两条行动线 | TE08/TE09 | 同时、主题相关、未知区分 |
| 小悬念 | IN01/IN05/EM01 | 必须回收关键必要信息 |
| 审美、运动、后期MV | RY05/RY06/RY07/MO05 | 生成无BGM；曲目未提供不虚构节拍 |
| 复杂动作难生成 | TE02/IC02/IC05 | 用户许可且合法省略，不能用插镜掩盖穿帮 |

选择顺序：用户硬约束/物理可行性→情绪、故事、节奏→注意力、画面关系、空间。Murch原则定性参考，不机械评分。连续Vlog仍可使用反应、正反打、动作匹配、J/L等；不需要改变故事顺序。高潮可慢切留白。用户锁定Classic最终镜序/时点不得改；默认保持其最终六镜结构。自动剪辑不授予特殊双端转场，未授权只建议。
