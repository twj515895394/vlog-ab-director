# Vlog AB Director v2：T04 声画与对白导演（Audio Director）

> 状态：**T04 自然语言声画规划规则**，不是音频引擎、视频剪辑器或 MiniMax H3 官方语法承诺。
> 证据：[用户实测成功的中文闭嘴 VO](../examples/voiceover-verified.md)；L/J-Cut 与 `<scenetrans>` 的模型兼容性仍待 T07 验证。
> 前置：T01 [策略](director_strategy.md) → T02 [时长](timing_engine.md) → T03 [连续性](continuity_handoff.md) → T03B [可选转场](transition_director.md)。T05 才负责完整可复制 H3 多 Part Prompt 模板装配。

## 1. 不可覆盖的 D3：生成阶段一律无背景音乐

Classic、Adaptive、Cinematic-led，以及每个独立的 15s Part 均遵循：

- `non_diegetic_music:` 下一行**只能是** `N/A`；不能出现音乐类型、曲名、乐器、BPM 或自动配乐指令。
- `overall_soundscape` **只**描述合理的环境声、人物对白/画外音、呼吸、笑声与 Foley（脚步、衣料、门、水花等）；不得加入钢琴配乐、治愈 BGM、无来源旋律或“自动配乐”。
- `detailed_description` 结尾原样保留无 BGM、防字幕、防 UI 的排版与内容：

```text
【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

- 用户需要 AI MV、音乐卡点或情绪配乐时，**仅在 Prompt 外**给出可选的后期配乐/剪辑建议；生成时仍无 BGM，不开启自动配乐。不能将后期建议误放到 H3 声场字段。
- 不能利用“咖啡厅里有现场音乐”等方式绕开生成阶段无 BGM 的已确认口径；除非未来用户明确修改 D3，否则本阶段只生成非音乐声场。
- `<d>[Chinese] ...</d>` 表达要发出的声音，**不是画面中应出现的字幕**。

## 2. 内部声音计划（不是新的 H3 顶层字段）

| 字段 | 说明 |
|---|---|
| `event_id` | 如 P1_Shot4_VO1，标记唯一事件 |
| `part_id / shot_id` | 使用 T02 当前 Part 的局部 0–15s 时间轴 |
| `speaker_id` | S1 / S2 等，与 T03 角色 ID 关联；环境声无需人物 speaker |
| `audio_kind` | on_camera_speech / offscreen_voiceover / ambient / foley / silence / audio_bridge |
| `utterance` | 口语文本与 `<d>[Chinese] ...</d>` 等语言标记 |
| `audio_start / audio_end` | 本 Part 声音事件的起止时刻；跨镜必须明确 |
| `speaker_visibility` | 画面中嘴部可见 / 不可见 |
| `lip_policy` | sync_lips / closed_lips / not_visible；可见口型不得自相矛盾 |
| `cut_relation` | none / L_cut / J_cut（剪辑语义，不是保证可用的 H3 参数） |
| `audio_carry` | 跨镜或跨 Part 的说话者与后期音轨衔接要求 |
| `evidence` | 用户实测有效 / 兼容候选 / 未实机验证 |

一个声音事件要能回答：**谁在说、何时说、是否出现在画面、嘴唇如何动作、声音来自哪个场景、是否跨镜延续**。

## 3. 五种声音状态与嘴型约束

### 3.1 画内直言 on_camera_speech

角色的口部可见并正在**真正对话**，指定说话人 S1/S2 和 `sync_lips`；不要同时要求嘴唇完全闭合。A 镜可以对镜自述，B 镜也可以拍到人物与同伴说话，**不能把 B 镜全部强制解释为画外音**。

```text
[Shot 1] A1，S1 右手自拍，嘴部清楚可见。她对镜头自然笑着说：<d>[Chinese] 今天来看看海。</d> 说话时嘴唇与 S1 的语音同步。
```

### 3.2 画外心声 offscreen_voiceover

**用户已报告实测成功、需要永久保留的有效范例：**

```text
此时她以画外音心声说道：<d>[Chinese] 果然如入深谷，甚是清净。</d> while her lips remain completely closed.
```

这句话明确了中文画外音声源、`<d>` 内容与画内人物闭嘴。它**没有**英文固定短语 `says in an off-screen voiceover:`，却仍是有效的兼容表达。英文写法可以选用，但**既不是必填字面短语，也不是语义 QC 的唯一通过条件**。

若画内角色嘴部清楚可见，画外心声应要求 `closed_lips`；若人物根本不在画内或嘴部完全不可见，使用 `not_visible`，不能声称已看见嘴唇闭合。**一镜同一角色同一时刻不能同时 `sync_lips` 和 `closed_lips`**。如果用户希望 B 镜里主角真的对同伴讲话，就应使用画内直言，不能硬写画外心声。

证据等级：用户报告过这条中文表达成功，**不代表已验证所有模型版本、所有镜头与动作**，也不保证用户案例 2.5 秒内戴耳机动作的物理稳定性。

### 3.3 没有台词 silence / ambient / foley

允许整个 Part 甚至整片**完全没有台词**，只保留环境与合理 Foley；不要为了固定镜数或 B 镜时长而强制生成口播。声音的「静默」可指无对白，**不强制消除用户希望保留的现场声**。

### 3.4 L-Cut：声音晚于画面切换结束

- S1 在 Shot 1 开口；在 Shot 2 画面已经硬切后，**同一个 S1 的声音**仍继续到某个明确结束时间。前后需要记录 `speaker_id`、声音起止区间及视觉切点。
- 示例：A1 自拍对镜说前半句 → 硬切 B1 景观，S1 画外继续说完后半句；B1 若可见 S1，则明确 `closed_lips`，若不见人则为 `not_visible`。
- 过去文档的 `<scenetrans>` 和 `continues seamlessly across the cut` 仅作为**历史兼容候选**。没有当前可复现实测证据证明该标签始终被 H3 支持；**不强制两镜都写 `<scenetrans>`**。可以先使用明确的自然语言说明发声时间/声源，T07 再对比验证。
- **跨独立 Part 的 L-Cut 不保证一次生成跨任务无缝音轨**；应保留可用声音素材，再由后期剪辑衔接或重配声。不要把完整台词在两个任务各自重新发一遍而产生重复音频。

### 3.5 J-Cut：下一场景声音早于对应画面进入

- Shot 1 还在城市街道时，**提前听到 Shot 2 林地的风/鸟声**，硬切之后才见林地。需要说明声音属于新场景，提前进入的时间与原环境如何混合。
- 如果是 S2 的下一场台词在 S1 的画面时先响起，必须说明 S2 是声音来源，并让**当前画面里不说话的 S1** 维持自然闭嘴，不能给 S1 错误同步嘴型。
- **跨独立 Part 的 J-Cut 要靠后期将下一任务的声音提前混入**，不是要求前一 H3 任务预知下一任务的音轨。
- J/L-Cut 是音频桥接/剪辑技巧，**不等同于 T03B 的摄影「神转场」**；使用普通硬切的边界也可有声音接力，依然不能生成 BGM。

## 4. 多人/双人：身份、发言轮次与口型不串位

1. 稳定绑定 `<Subject 1> = S1`、`<Subject 2> = S2`；每句台词标记归属。不要靠声音描述自动猜说话者。
2. 单人说话时，其他能看到嘴部的人应表现倾听/自然闭嘴，不出现无源口型；在远景不可见嘴部可用 `not_visible`。
3. 优先每镜安排少量**轮次明确**的对话，不能把两个角色多轮长对白塞进一小段时间。
4. 齐声欢呼仅在故事确实需要时使用 `(S1,S2)`，两人均可见且发声时可分别要求嘴型同步。
5. 跨镜续说的 `audio_carry.speaker_id` 必须等于原说话者；人物视角从 A 切到 B 不代表声音换人。
6. 多人画外音须显式区分声源（哪一个人心声、谁未开口）。同一时间多个独立 VO 重叠时需确认符合剧情，不自动混音造成听不清。

## 5. 根据镜头时长而不是固定台词字数填满声音

- **Classic 2.5 秒**：保留原 v1 经验预算，中文约 **6–12 字**、英文 **4–8 词**，15 秒常规安排 **2–3 镜**有台词，其余留白。这是兼容基线，**不是模型成功的硬承诺**。
- **Adaptive/Cinematic**：先计算 `speaking_window_s = shot_duration_s − pause_s − non_speech_action_s`；需要讲话时必须有正的可说话窗口。中文以约 **3–4 字/秒**作为审慎经验估计，不足时缩短、分镜、改画外音或减少动作。
- 例如 2.5s 镜头需要 0.5s 休息与 0.5s 非说话动作，剩下 1.5s；按 3–4 字/秒估约 4–6 个汉字。**与旧版 6–12 字经验建议不同，不应把两组数字强行视作相同硬限制**。
- 如果用户给出必须逐字保留的台词，不能静默删改台词；应指出镜头预算不足，并提出改更长镜头、减少动作或分段的可行修订方案。
- Cinematic-led 可以零对白，B 镜不要求一定画外心声；减少叙述有助留出情绪与环境层次。

## 6. 现有 H3 六段式 Prompt 的装配位置（T05 前置规则）

| 字段 | 必要内容 |
|---|---|
| `subject_definitions` | 角色 S1/S2 与音色/语言，不能编造未上传参考图 |
| `summary` | 作品调性，生成阶段无 BGM |
| `retention_analysis` | 说话者身份/声线跨镜稳定 |
| `detailed_description` | 对每个有声音的镜头明确发言者、`<d>` 台词、画内/画外、嘴型和跨镜起止关系；尾部保留防字幕/无 BGM 原负向块 |
| `overall_soundscape` | 场景环境声、Foley、人物呼吸/说话与合理声画连接；**不写任何 BGM 生成指令** |
| `non_diegetic_music` | 严格为 `N/A` |

内部 `Audio Plan` **不是第七个 H3 顶层字段**；每个独立 15s Part 都必须有各自六字段，T05 再实现完整 Adaptive/Cinematic 装配。

## 7. T04 静态 QC：应拒绝与应接受

**HARD（必须修正）**：
- 生成声音字段里要求 BGM，或 `non_diegetic_music` 不等于 `N/A`；
- 只因为 VO 没有英文固定短语而拒绝用户中文成功句；
- 同一可见人物/同一时刻同时要求开口同步和完全闭嘴；
- 多人场景说话人不明、S1/S2 无事件换声线或嘴型错误归属；
- 声音跨镜但没有明确说话者/时间关系，或重复生成完整台词；
- 声称两个独立任务靠文字标签即可确保音轨精确跨任务无缝；
- 用户要求无台词却自动加台词，或把 `<d>` 误变成字幕文字。

**SOFT（建议改进）**：
- 2 秒镜头同时安排复杂动作和长口播；
- 每个 B 镜都强塞画外音，破坏 Cinematic-led 治愈感；
- 环境声与场景不一致、音频覆盖重要 Foley；
- 没有实际模型实测却把 `<scenetrans>` 当作每个跨镜都必填的合法性证明。

**保留正例**：`此时她以画外音心声说道：<d>[Chinese] 果然如入深谷，甚是清净。</d> while her lips remain completely closed.`

## 8. 能力与实测证据边界

- T04 交付的是 **可执行文本规则**：画内对白/闭嘴 VO/L-Cut/J-Cut/无台词、多人发声归属、按时长规划与 D3 无 BGM。
- T04 没有交付真实声音拼接程序、跨 Part H3 音轨锁定、T05 多段完整 H3 模板或 T06 自动语义判定器。
- 当前中文 VO 的成功证据来自**用户报告的单个具体片段**；T07 仍需实机验证声画行为及 `<scenetrans>` 兼容性。
