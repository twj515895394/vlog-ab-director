# Vlog AB Director v2：Auto 导演策略路由（T01）

> 状态：T01 已实现的**自然语言策略路由规则**（不是视频生成 API，也不是程序化分类器）。  
> 设计依据：[v2 详细设计](../docs/design-v2-director-engine.md) 第 3–4 章和 D1–D5。  
> 范围边界：T01 负责识别、决策、约束传递；**T02 已定义可变镜头时间预算**，T03 已接入跨段状态交接，T03B 已接入可选转场导演规则；Adaptive/Cinematic 正式模板装配已在 T05 接入。不可把文字规则等同于 H3 实机效果。

## 1. 目标及不变约束

**v2.1 前置门禁**：先由 [Creative Director](creative/creative_director.md) 识别是否需要创意讨论；只有当前 [Creative Brief](creative/creative_brief.md) 已确认/委托、创意QC通过且用户明确要制作（或充分明确的任务直接请求成品）才进入 T01。仅要点子/继续讨论时不得运行成品装配。进入制作后，Skill **默认使用 Auto** 先判断怎样拍，而不是机械套用 A1-B1-A2-B2-A3-B3。用户可直接要求 `Classic AB`、`Adaptive AB` 或 `Cinematic-led` 覆盖 Auto 的推荐。

- **A 镜（主观）**：人物对镜头交流、身临其境和情绪陪伴；现代真实自拍通常右手持机。无手机的古风/仙侠世界观采用自然的近距离主观跟拍/随行视点，**不凭空出现现代手机**。
- **B 镜（客观）**：空间、动作、人物整体造型、场景光线、环境氛围；镜头的作用应有叙事理由。
- 用户指定 `Classic AB`、固定六镜、每镜 2.5s 或严格 A/B 交替时，**必须固定为 Classic**；不可悄悄修改镜数、时间点和交替顺序。
- 视频**生成阶段始终没有 BGM**，仅允许现场环境音、人物对白/画外音和 Foley。模型 `non_diegetic_music: N/A`；想要音乐节拍可另给后期剪辑建议，不能变成生成背景音乐。
- 最终成片最长 **300秒**；每次H3仍独立15s；有限任务数按素材预算，不能承诺一次生成长片。叙事组织由[Editing Auto](editing/editing_auto_strategy.md)独立选择CONTINUOUS/EDITED/HYBRID，摄影模式不决定是否承接。
- Part 间**技巧性转场是可选建议**：T03B 已接入按场景判断的 `none / suggest_only / planned_pair`；Auto 默认只建议、不改 Prompt，只有用户明确选用或授权直接安排才成对改写；没有适合技巧应正常硬切；不得用淡入淡出或一键特效替代摄影/剪辑技巧。
- 默认输出给用户可复制的完整 H3 六段式 Prompt；内部决策理由可压缩成必要的简短说明，完整状态表和 QC 仅按需展示。

## 2. 输入提取：Director Brief

从确认的 Creative Brief、用户自然语言、明确参数和可用参考素材中提取（映射参见 Creative Brief 第4节）；题材不自动决定摄影模式：

| 字段 | 内容 | 未指定时 |
|---|---|---|
| `theme` | 日常记录、旅行、情侣/互动、微剧情、人物展示、氛围混剪、古风等 | 由故事推断 |
| `primary_goal` | 与观众交流/人物表演/场景探索/视觉审美/剧情推进等 | 识别最突出的目标 |
| `camera_intent` | 自拍、第三人称、A/B 混合、纯氛围、禁止自拍 | 无明确要求 |
| `constraints` | 明确六镜、2.5s、固定顺序、运镜、禁止手机或人物露脸等 | 无额外硬约束 |
| `characters` | 数量、交互关系、持机人、身份与服装 | 单人，按世界观确定持机方式 |
| `setting` | 场景、时间、光照、重要道具与相邻场景关系 | 不编造影响剧情的关键事实 |
| `duration` | 当前 Part 时长、最终成片目标时长 | 15s 单片 |
| `aspect_ratio` | 9:16 / 16:9 | 用户指定优先，否则依发布场景推断 |
| `references` | 角色图、道具图、场景图、是否已上传 | 无图不能虚构 `<Picture N>` |
| `audio` | 对镜讲话、画外音、静默、环境声、后期配乐需求 | 以故事中的声音合理性判断 |
| `transition_preference` | none / 仅建议 / 用户指定技巧 / 明确授权导演按需实际应用 | 未指定：按场景评估，默认只建议、不能强制或私自改 Prompt |
| `language` | 用户想使用的 Prompt 语言 | 跟随用户 |

这是一份**内部决策草稿**，不是每次都展示给用户的大表单。只有缺少真正影响故事或交付的必要信息，才询问一个针对性问题；其他按上表默认推断。冲突信息按第 3 节处理。

## 3. 路由优先级及单一路径决策（必须按顺序执行）

| 顺序 | 检查项 | 结果与解释 |
|---|---|---|
| **P0** | 用户显式要求导演模式（Classic / Adaptive / Cinematic） | 直接锁定该模式，除非另有互斥的明确硬约束 |
| **P1** | 用户明确固定 6 镜 + 2.500s / A-B-A-B-A-B，或说「按旧版」/「经典 AB 严格交替」 | 锁定 `Classic AB`，**不得因为题材像大片而覆盖**；如果仅点名六镜而不指定间隔，原则上按 Classic，另有不等长要求需显式化冲突 |
| **P2** | 用户明确「不要自拍」「以 B 镜为主」「纯人物质感氛围混剪」「少台词」 | 选择 `Cinematic-led`；若同时明确想有少量主观感，可保留有限主观近景/第一人称声源 |
| **P3** | 旅行探索、城市走访、双人互动、微剧情、多个叙事节点、自拍与客观景别希望按故事配比 | 选择 `Adaptive AB` |
| **P4** | 强调聊天、日常互动、对镜陪伴、真实记录但尚未指定 Classic 结构 | 首期选择 `Adaptive AB` 并加强 A 镜；**`POV-led` 只预留，不作为可用独立路由** |
| **P5** | 题材、主体、镜头目的均不明确，且无法判定更合适模式 | **保守回退 `Classic AB`**，避免凭空炫技 |
| **Safety / World** | 明确古风、仙侠或禁止手机 | 在已选模式中启用无手机的自然主观近景/跟拍；**世界观约束只调整机位实现，不自动等于 Classic** |
| **Delivery** | 目标时长大于 300s，或要求 H3 一次生成长片 | 不做错误承诺；注明 300s 成片上限及独立 15s 任务限制，交给已实施的 T02 时间预算及T05 完整装配规则 |

处理同时出现多个信号时：**用户明确镜头硬约束优先于题材推断**；如果用户显式说「经典六镜，但不要任何 A 镜」等互斥要求，必须指出冲突并请求用户选择哪项优先，不能暗中忽略一个要求。若两种题材信号相近而无明确镜头硬约束，按作品的主要视觉功能做最简单的选择，不需要罗列多个候选让用户选。

> 不实现打分器、关键词机械命中或「自动强行猜视频风格」；这套规则服务于语言模型依据语义作出可解释且一致的选择。

## 4. 三种可选策略的执行契约

### S1 — Classic AB（稳定兼容 / strict）

- 单 Part 15s：**6 镜，每镜 2.500 秒**，A1-B1-A2-B2-A3-B3；对应 0、2.5、5、7.5、10、12.5、15 秒的切点。
- 30s：两个独立 15s 任务，Part 2 从局部 0s 重新计时。
- 允许场景、角色、情绪、摄影美学变化；**不允许修改 Classic 的镜数/顺序/时间码**。
- 复用 `templates/template_15s_single.md`、`templates/template_30s_twopart.md`。
- 适合以已验证结构优先的用户；**不是所有视频的统一默认模板**。

### S2 — Adaptive AB（根据叙事灵活配比）

- A 负责主观交流与人物体验，B 负责客观动作、空间、构图与光影；**不强制等量，也不强制 A/B 严格轮换**，可以 A-A/B-B，但每镜必须承担明确职责。
- 自拍互动较多则增加 A 镜；旅拍空间探索较多则增加 B 镜；不能把「运镜华丽」替代故事意义。
- 当用户未指定镜数和切点时，不把 Classic 的 6×2.500 秒作为全局硬规则。
- **阶段说明**：T01 已实现的是**选择该策略并传递设计约束**；动态镜头时间预算现已在 [T02 timing_engine](timing_engine.md) 定义，标准化可复制的 Adaptive 模板已在 T05 接入。已有非等长时间轴及正式文本模板，但尚无 H3 实机稳定性证据；如果用户指定非等长，不得私自改写为 Classic。

### S3 — Cinematic-led（以外部摄影为主）

- 视觉故事、人物形象、氛围、低对比柔光或极简情绪表达优先；**B 镜明显占主导**，A 镜可减少或由少量主观近景/生活化摄影替代，但不能强行插入「对镜头打招呼」。
- 可使用场景音、人物呼吸、有限画外音，减少毫无必要的台词；**不等于必须添加背景音乐**。
- 不应自动退化成毫无生活在场感的纯广告图集；用人物的目光、动作、空间关系与叙事线保留 Vlog 特征。
- **阶段说明**：和 Adaptive 一样，T01 仅先打通路由与策略约束；Cinematic-led 时间预算已在 [T02 timing_engine](timing_engine.md) 定义，正式 H3 模板已由 T05 提供。

### 保留扩展 — POV-led

- 仅预留「强调 A 镜的自适应配置」，目前**不创建第四个已完成策略**；T01 针对偏主观聊天的请求仍路由到 Adaptive AB。
- 不强制现代手机：古风/奇幻无手机设定应使用适合世界观的主观镜头，而非现代手机或镜子。

## 5. 路由输出契约

每次内部至少确定：

```text
director_mode: Classic AB | Adaptive AB | Cinematic-led
reason: 一句话解释主要判断依据（只在必要时向用户展示）
hard_constraints: 用户指定必须遵守的拍摄/时长/世界观要求
camera_intent: A 镜与 B 镜的分工及期望主次
duration_scope: 15s task / multipart plan (<=300s final)
audio_policy: NO_BGM_IN_GENERATION
transition_policy: OPTIONAL, never force at part boundaries
prompt_output: complete six-section H3 prompt by default
```

- **路由输出不是模型的六段式 Prompt 本身**，是写 Prompt 前的创作规划。默认结果依 D4 应让用户直接复制完整 Prompt，不强迫阅读这份内部状态。
- T01 路由与 T02 动态时间预算已定义；不提前宣称状态机、跨段特殊转场、自动 QC 或 H3 多段成品装配已完成。
- 对于确实超出已接入的 T02/T05 规则或尚未验证的模型能力的细节，应明确能力阶段并用保守可行的镜头规划做当前交付，**不可暗自把用户明确要求的非等长镜头改成 Classic**。
- 如果用户明确选择 Classic，**不允许被默认 Auto 路由改写**；保留旧模板、旧标签与双段参考图编号方式。

## 7. 后续阶段与本文件的关系

- **T02（已完成文字规范）**：见 [timing_engine.md](timing_engine.md)，提供 Adaptive/Cinematic 15s 镜头预算、有限任务预算及剪后净时长账本；不等于 H3 已经逐帧执行。
- **T03（已接入规范）**：参见 [continuity_handoff.md](continuity_handoff.md)；已定义跨镜/跨段的人物、手、道具和场景状态交接，模型行为与视频效果仍待后续验证。
- **T03B（已接入文字规则）**：见 [transition_director.md](transition_director.md) 和 [46 技巧库](../docs/transition-techniques-library-v2.md)；按场景判断 `none / suggest_only / planned_pair`，仅实际采纳/授权时才要求双端镜头，始终不强制转场。
- **T04（已接入文本规则）**：参见 [audio_director.md](audio_director.md)；已统一用户实测中文闭嘴 VO、多人说话者/口型、L/J-Cut 和无 BGM 约束，英文固定短语不是必填。
- **T05（已接入）**：根据 [H3 Adapter](model_h3_adapter.md) 输出可复制的单段/多段模板和逐任务引用；
- **T06/T07**：静态 QC 和 H3 实机生成效果回归。

**定义「T01 完成」**：默认 Auto 路由可读取，三条正式策略及优先级有可执行约束；中英文 Skill 入口语义一致；用户指定 Classic 不退化；题材典型案例可按规则得出预期策略。**不把未实现的后续功能冒充为 T01 已实现。**
