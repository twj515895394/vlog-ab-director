# 共创样例 02 — 只有人物参考

本例为人工编写的假设对话，不附实际图片，不声称图像已上传。

**用户**：我有个古风女性角色，想做电影感视频，还没故事，30秒，无手机，柔光、低饱和。

**Agent**：保留古风造型、30秒、无现代手机。没有图时身份/服装细节先以用户已描述为准；其余暂定为虚构，不猜真实经历。可以走三个不同方向：

- A《一盏茶的清晨》G07/G01、S02：清晨庭院里整理茶具，坐下感受水汽和鸟鸣。记忆点为袖边与茶雾。低难，30秒。
- B《溪边的归还》G07/G05、S03：主角拾起被风吹到干燥石台的叶片，又把叶片放回树下。记忆点是手中叶片与自然回应。低难，15–30秒。
- C《走进另一重春色》G02/G10、S06/S07：沿古巷发现竹林深处阳光，停步回望；可以自然硬切，不强制跨空间神转场。中难，30秒。

**用户**：不要茶具，不想有太多互动，我希望纯人物审美和沉浸感。

**Agent**：那保留你的人物、古风、柔光、无手机、30秒，排除茶具。改为两种非强剧情的表达：
- D《风过衣袂》：同一人物沿廊道缓步、停下，再于竹影中回眸；G06+G07/S08，记忆点是风、衣料与侧颜。
- E《三步皆春》：庭院静立、经过花枝、在光中驻足；G10+G07/S07，构图和人物轮廓首尾呼应。
不强加形成人物冲突、台词或手机自拍。哪一种更贴合你想看到的角色？

**用户**：D，先聊聊，不要生成。

**Agent**：以D作为讨论中的候选，保留无手机/无茶具等约束，下一轮可比较偏纪录感、偏艺术电影的视觉表现；不生成H3。
