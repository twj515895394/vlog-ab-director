# 300秒两种组织方式的有限素材预算

## A CONTINUOUS：5分钟工作室轻剧情Vlog
同一虚构成年花艺师、同一桌、同一瓶、同一套衣服；一组明确顺序动作链。普通硬切、每个任务保留完整15s；不是要求一镜到底，也不宣称自然连续已实际达到。每个动作有明确前后状态（例如剪刀只由一只空闲手操作，插花后花在瓶中；下段不得回到未插入状态）。生成依赖P01→P02…→P20；按实际上一任务保留出点核对下一任务。人物主线：完成一瓶花；实际裁切导致不足时明确预算冲突或获得补镜授权。

|任务|行动|成片(s)|
|---|---|---|
| P01 | 打开工作室门 | 0–15 |
| P02 | 走到工作台 | 15–30 |
| P03 | 摆放空花瓶 | 30–45 |
| P04 | 挑选第一枝花 | 45–60 |
| P05 | 修剪第一枝花 | 60–75 |
| P06 | 将第一枝插入瓶 | 75–90 |
| P07 | 观察第一枝倾斜 | 90–105 |
| P08 | 挑第二枝 | 105–120 |
| P09 | 修剪第二枝 | 120–135 |
| P10 | 将第二枝插入瓶 | 135–150 |
| P11 | 调整两枝位置 | 150–165 |
| P12 | 挑一枝枝叶 | 165–180 |
| P13 | 修整枝叶 | 180–195 |
| P14 | 插入枝叶 | 195–210 |
| P15 | 检查整体轮廓 | 210–225 |
| P16 | 微调位置 | 225–240 |
| P17 | 把剪刀放回桌面 | 240–255 |
| P18 | 退半步观察 | 255–270 |
| P19 | 安静端详 | 270–285 |
| P20 | 露出自然微笑并留白 | 285–300 |

20×15=300无预留裁切；裁1秒仅299秒。并不强制剪辑型结构，连续Vlog原有模式适用；每任务摄影Auto独立于叙事组织。

## B EDITED/HYBRID：5分钟六章故事预算
六章分别为早晨计划、上午准备、途中体验、意外变化、作出选择、结束余韵；各含4个15秒任务（可按剧本局部连续或独立素材）。每章4×12.5=50s；24×15=360名义，24×12.5=300计划净长，60余量。默认每段保留[1,13.5)，剪点须实际核对；不是自动生成/剪辑保证。

|章节|任务|目标(s)|功能与边界|
|---|---|---|---|
| C1 | Q1–Q4 | 0–50 | 建立人物和计划 |
| C2 | Q5–Q8 | 50–100 | 准备过程可省略非核心动作 |
| C3 | Q9–Q12 | 100–150 | 人物体验，选择代表性片段 |
| C4 | Q13–Q16 | 150–200 | 小事件触发，反应镜 |
| C5 | Q17–Q20 | 200–250 | 人物主动选择，局部连续 |
| C6 | Q21–Q24 | 250–300 | 结果和情绪留白 |

任务数24是此规划假设，非固定默认。用户若最多20，此预算不成立，需减少损耗或另行授权素材；不能把补镜隐形计入。此为预算表，不是24条完整Prompt或成片。所有Clip为planned，后期音乐仅可选，无BGM生成。
