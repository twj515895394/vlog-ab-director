# T03 状态迁移与多 Part 连续性回归案例

> 阶段：T03（规则级/文本静态测试）；**不是自动运行的检测程序，也不是 H3 真实视频渲染结果**。  
> 规则来源：[continuity_handoff.md](../references/continuity_handoff.md)、[rules_state_machine.md](../references/rules_state_machine.md)。  
> 正例模型：[植物园 P1/P2/P3 内部交接样例](../templates/segment_handoff_example.md)；Classic 视频 Prompt 冻结基线仍见 [T00 30s](../examples/classic-ab-30s.md)。

## 1. 判定级别

- **PASS / TEXT**：根据明示的 `entry_state / visible_action / exit_state`、`cut_event`、`handoff_out` 可以推导出合法状态；这是**文字一致性**，非生成效果。
- **FAIL / HARD**：同手多占用、道具无事件瞬移、人物换身份、旧场景锚点无故移动、非法参考图编号、需要但缺少 handoff。
- **REVIEW / SOFT**：文本虽可解释，但动作在镜头时长内过多、空间/天气变化生硬、身份/位置描述不足。
- **OUT_OF_SCOPE**：完整 H3 多段模板装配、创意转场推荐、视频帧级物理效果分别留到 T05/T03B/T07。

## 3. 端到端边界检查清单（手工 / 文本级）

按照真实故事顺序、**每个 Part 每个镜头**执行：

1. 确定每镜 T02 局部区间是否闭合，写入该镜 `entry/action/exit`；
2. 给每人稳定 `character_id`，记录发型/衣着/位置/朝向、是否实际持手机、左右手占用；
3. 给核心道具稳定 `prop_id` 和 `appearance_lock`；镜末更新位置、手、收纳状态；
4. 如果入镜状态不同于上一镜出镜，必须注明**可行的镜内动作或合法的镜间 cut/jump 事件**；
5. 若发生地点跳跃，区分随人移动的持有物与仍留在原 `scene_id` 的固定锚点；
6. 遍历所有相邻 Part（例如 P1→P2、P2→P3、…、P7→P8），**逐一**核对 handoff；
7. 每个 Part 以当前**实际上传的素材**建立 `asset_id → Picture N` 清单；无图则不引用 `Picture N`；
8. 只核对声音发言者归属与是否跨镜，复杂 L-Cut/H3 语法留 T04；始终 **无 BGM**；
9. 对所有边界默认允许普通硬切/`none`，不以「缺神转场」作失败理由；
10. 记录 HARD / SOFT 与修正；**不声称模型一定按状态表生成**。

## 4. 附加测试：一条已存在的 v1 30 秒案例不应被 T03 误拒

[T00 植物园案例](../examples/classic-ab-30s.md) 的 P1 尾镜右手低握手机、左手握折页，P2 首镜右手举机、左手仍持折页，在同一温室门的外侧/内侧变化。它可由 `walk_through_same_door + raise_camera` 两个**切点事件**解释，不是「手机突然消失」「地图瞬移」「门跟随角色移动」。

T03 只能通过**补足内部交接状态说明**保护兼容性，不得改动 T00 完整 Prompt 的 Classic 六镜时间点，也不能强迫新增穿越门洞的视觉特效转场。

## 5. 阶段状态与后续验收

- **T03 已交付的内容**：状态字段与迁移约束、道具/手资源规则、切点省略、时间与地点跳跃、历史2–8 Part handoff示例（现行任意有限任务的连续依赖及实际边界）、逐任务图片映射、32 个正反例。
- **静态核验**：可以检查规范字段、逻辑示例和引用清单的**文字自洽性**。没有仓库内独立的自动语义判定程序。
- **待验证**：加载 Skill 后是否稳定遵循全部规则；H3 是否真的避免手变形/道具漂移；跨段是否视觉连续；T03B 是否推荐合适的剪辑转场。这些均不因 T03 文档存在而提前标为通过。
