## 4. 最小静态检查方法（T00 可人工执行）

1. **提取真实 Prompt**：只检查完整示例中的 ```text...``` 代码块，不把外层使用说明里的 `<Picture 3>` 反例当作当前生成引用。
2. **逐任务检查**：单任务六个顶层字段、六个 Shot、A/B 顺序及五个 `At 00:... HARD CUT TO` 切点；最后时长均为 15s。
3. **多 Part 引用**：仅当前任务上传的两张资产，按实际顺序映射 `Picture 1/2`，不能从全局素材索引直接复制 `Picture 3`。
4. **负向块与声音**：`【禁止项】`、`【强制声明】` 保持空行，模型 Prompt 声场不得要求 BGM，`non_diegetic_music` 的值必须是 `N/A`。
5. **语义检查**：右手持机、左手交互、道具生命周期与跨 Part 的第一/最后镜状态相容；判断中文画外音时不以英文固定短语为唯一条件。
6. **记录结论**：结构问题可在 T00 记录并修正示例；真实的口型、手部、转场、字幕与视频音质只能在 T07 的实机阶段确认。
